Place optional 3D face-part prefabs here when using resource paths.

Examples:
- Assets/Resources/ARStickerBooth/FaceParts/Glasses.prefab -> resourcePath: ARStickerBooth/FaceParts/Glasses
- Assets/Resources/ARStickerBooth/FaceParts/Nose.prefab -> resourcePath: ARStickerBooth/FaceParts/Nose
- Assets/Resources/ARStickerBooth/FaceParts/Mouth.prefab -> resourcePath: ARStickerBooth/FaceParts/Mouth

You can also assign prefabs directly in BoothFrontendController.tracked3dFaceParts.
